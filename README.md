## 💎 Core Architecture & Mega Features

### 👨‍🏫 1. Faculty Administration Control Hub
* **Multi-Branch & 4-Year Integrated Cohort Matrix:** Scalable support filter nodes for CSE, ECE, EE, CE, and ME streams spanning Freshman (1st Year) to Senior (4th Year) academic tiers.
* **Dual-Tier Attendance Logging Engine:** Separate computational tracking vectors for **Theory Lectures** and **Practical Labs** with a strict real-time MAKAUT 75% mandatory threshold enforcement system.
* **Smart One-Click Attendance Grid:** Dynamically populated interface allowing professors to switch student present/absent logs instantly.

### 📊 2. Multi-Tier MAKAUT Evaluation Engine
* **Continuous Internal Assessments:** Dedicated continuous tracking infrastructure logging **CA1, CA2, CA3, and CA4** sessional grades alongside Mid-Sem Exams and Assignments.
* **Practical & External Board Matrix:** Precision grade entry architecture capturing internal **PCA1, PCA2**, and External Board University **Viva-Voce** evaluations.
* **4th Year Industrial & Terminal Innovation Metrics:** Comprehensive logs archiving Major B.Tech Graduation Projects (0-200 Marks) and Corporate Industrial Internships.

### 🏠 3. CGEC Infrastructure & Welfare Sub-ledger
* **3rd & 4th Year Boys Hostel Room Mapping:** Contextual constraint system enforcing hostel allocations and live mess bill dues balance strictly for junior and senior cycles while locking freshman structures.
* **West Bengal Scholarship Welfare Node:** Live tracking state for elite state-sponsored portals like **SVMCM (Swami Vivekananda)** and **Oasis Gateway**.

### 📜 4. Student Transcript & Digital Script Vault
* **Evaluated Answer Script PDF Lifter:** Faculty can link scanned answer documents via a dynamic base64 FileReader string. Students can instantly download their checked exam scripts.
* **MAKAUT Weightage Converter:** Automated logic translating aggregate matrices into cumulative SGPA scores and calculating final weight percentages via the official university formula: `(SGPA - 0.75) * 10`.
* **Automated Merit List Leaderboard:** Real-time array sorting algorithm calculating live branch-wise class ranks instantly.
